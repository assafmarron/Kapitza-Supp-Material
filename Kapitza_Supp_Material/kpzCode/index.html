Parameters
Environment

EARTH: base rests on a spring-supported platform — soft, recoiling base.
FREE: base floats in space. Only the bob feels gravity; the base reacts via Newton’s third law.
CLASSICAL: base is exactly immovable (infinite mass) — the textbook Kapitza pendulum, with zero base recoil to contaminate the pivot motion.

Mode
Pivot frequency 20.000 Hz

Stability requires f > ~70 Hz here. Drag below that threshold to watch it fall.

Pivot amplitude 10 mm

Half-stroke of the pivot’s vertical motion (a full cycle spans 4 amplitudes). Appears as a in the classical stability formula a·ω ≥ √(2·g·L) — larger amplitude makes the pivot easier to stabilise.

Rod length 100.0 cm

Length of the rod from pivot to bob (log scale, 1–100 cm). Appears as L in the classical stability formula a·ω ≥ √(2·g·L) — a longer rod raises the frequency needed for stability.

Bob mass 50 g

Mass of the pendulum bob (log scale, 1 g–1 kg). Scales the rod's reaction force on the base — a lighter bob means less base recoil.

Base mass 50 kg (rigid)

Mass of the base (log scale, 50 g – 50 kg). At 50 kg the base barely recoils — stability holds. Drag left to reduce mass; Kapitza fails near 500 g.

Spring constant k 1000 N/m

Stiffness of the base spring (log scale). Only significant when base mass is low.

Base mass 50 kg

Mass of the free-floating base (log scale, 10 g–50 kg). Heavy base barely recoils — Kapitza stabilisation holds. Light base recoils strongly and can break stabilisation.

Base mass and spring constant are not applicable here — the base is pinned exactly at rest (y_base ≡ 0). This isolates the pendulum’s response to pivot oscillation from any base recoil.

Initial angle 1°

Starting tilt of the rod from vertical. Larger angles are harder to stabilise.

Stop at angle 90.0°

Automatically pauses the run as soon as |rod angle| reaches this value, and shows the elapsed time to get there — useful for timing how fast the angle grows at a given frequency. Default 90°; 0° = off (run continues indefinitely, until a physics-based stop limit fires or it's paused manually).

Run time limit 20.0 s

Automatically pauses the run once this much simulated time has elapsed, independent of any angle-based stop. Default 20s; 0 = off.

Stop on ODE mismatch

When off, the sim-vs-ODE checks (CLASSICAL mode, 1 m rod) no longer stop the run; the ODE charts still show any difference. Can be switched during a run.

History window 25 s

How much simulated time is kept for the charts. 0 s disables history recording entirely (charts stay blank) — useful for fast/long runs where the live charts aren’t needed.

Sim steps per amplitude (SpA) for f>10Hz (for f≤10Hz SpA=50) 25

Integration steps per pivot amplitude (a quarter of the oscillator cycle, so steps/cycle = 4× this) — sets the simulation’s time step (dt). Fixed at 50 (this slider is ignored) when the pivot frequency is 10 Hz or below, for precision in the slow gravity-driven fall. Higher = more accurate but slower; lower = coarser and faster, and can eventually become numerically unstable.
